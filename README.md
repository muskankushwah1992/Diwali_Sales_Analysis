# 🛍️ Diwali Sales Analysis

## 📌 Project Overview
Is project ka main objective Diwali sales dataset ka **Exploratory Data Analysis (EDA)** karna hai taaki customer purchasing behavior, top-selling product categories, aur target demographics ko samjha ja sake.

## 🛠️ Tools & Libraries Used
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn

## 📊 Key Insights & Findings
* **Gender & Age Group:** Single and married women aged **26-35 years** are the highest buyers.
* **Top States:** Uttar Pradesh, Maharashtra, aur Karnataka se sabse zyada orders aur sales aayi hain.
* **Occupation:** IT Sector, Healthcare, aur Aviation field me kaam karne wale log sabse zyada spend karte hain.
* **Product Categories:** **Food, Clothing & Apparel, aur Electronics** categories me highest revenue generate hua hai.

## 💡 Business Recommendation
Diwali season ke dauran marketing campaign aur promotional offers ko **26-35 age group ki working women** aur **Food/Clothing categories** par focus karna chahiye.
